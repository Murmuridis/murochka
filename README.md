# Мурочка 🧶

Дневник давления и напоминания о лекарствах. Flutter + SQLite, Android. Весь интерфейс — «вязаный»: лицевая гладь, резинка, фетровые заплатки с пунктирными стежками, клубки и пуговицы.

## Экраны
- **Главный** — котик в клубках, «Записать давление», «Мои лекарства», «Статистика», карточка ближайшего приёма. Шестерёнка — настройки, сердечко — отметки «Сегодня».
- **Запись давления** — систолическое, диастолическое, пульс, дата и время, самочувствие (5 смайликов), заметка.
- **Лекарства** — вязаные таблетки (форма и цвет на выбор), доза, время, переключатель вкл/выкл, корзинка с клубками.
- **Напоминание** — котик с сердечком, «Пора принять лекарство!», кнопки «Я приняла» и «Отложить на 10 минут». Эти же кнопки есть прямо в уведомлении; на заблокированном экране напоминание открывается целиком.
- **Статистика** — вкладки Давление / Пульс / Лекарства, неделя со стрелками, график, средние значения, «Все записи» (с копированием дневника для врача).

Иллюстрации лежат в `assets/images/` — вырезаны из макета. Если есть версии в большем разрешении, просто замени файлы с теми же именами.

## Сборка через GitHub Actions
1. Создать репозиторий и залить туда содержимое папки.
2. Actions → **Build APK** запускается сам при push (или вручную).
3. Скачать артефакт `murochka-apk` → `app-release.apk` → установить на телефон.

Папку `android/` генерирует CI (`flutter create`), а `tool/patch_android.py` дописывает разрешения, ресиверы уведомлений, название и иконку.

## Локально
```
flutter create --platforms=android --org com.murochka --project-name davlenie .
python3 tool/patch_android.py
flutter run
```

## После установки
- Разрешить уведомления при первом запуске.
- На Xiaomi/Huawei/Samsung стоит отключить «оптимизацию батареи» для приложения, иначе напоминания могут опаздывать.
